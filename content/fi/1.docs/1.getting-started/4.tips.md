## Bun-komennot
 
Komentokehote

- `bunx nuxt typecheck` check types
- `bunx nuxi cleanup` cache & `/.nuxt/` clearing
- `bun update --interactive` to choose which depencies to update
- `bun why zod` which dependency pulled the package
- `bun audit` look for security vunerabilities
- `bun info` metadata for registries
- `bun pm pkg set author = 'Cat, Kitten'` modify `package.json`
- `bun pm version` update package version to new release

Työkaluja

- `import data from './data.yml'` YML imports
- `import { sql, SQL } from 'bun'` Postgres, MySQL, SQLite
- `import { redis } form 'bun` Key Value stores

## rssSchema

```ts
import { z } from 'zod/v4'

const enclosureSchema = z.object({
  url: z.string().url(),
  length: z.string().optional(),
  type: z.string().optional(),
})

const guidSchema = z.object({
  value: z.string(),
  isPermaLink: z.boolean().optional(),
}).catchall(z.string().transform((v) => v))

const itemSchema = z.object({
  title: z.string().optional(),
  link: z.string().url().optional(),
  description: z.string().optional(),
  author: z.string().optional(),
  category: z.string().optional(),
  comments: z.string().optional(),
  pubDate: z.string().optional(),
  guid: guidSchema.optional(),
  enclosure: enclosureSchema.optional(),
  source: z.string().optional(),
})

const channelSchema = z.object({
  title: z.string(),
  link: z.string().url(),
  description: z.string(),
  language: z.string().optional(),
  lastBuildDate: z.string().optional(),
  pubDate: z.string().optional(),
  managingEditor: z.string().optional(),
  webMaster: z.string().optional(),
  category: z.string().optional(),
  ttl: z.string().optional(),
  items: z.array(itemSchema).min(1),
  image: z
    .object({
      url: z.string().url(),
      title: z.string(),
      link: z.string().url(),
    })
    .optional(),
  textInput: z
    .object({
      name: z.string(),
      description: z.string(),
      title: z.string(),
      link: z.string().url(),
    })
    .optional(),
})

const rssSchema = z.object({
  rss: z
    .object({
      version: z.string().refine((v) => v.startsWith('2'), {
        message: 'RSS version should start with 2 (RSS 2.0 is common)',
      }),
      channel: channelSchema,
    })
    .optional(),
  channel: channelSchema.optional()
})
type RssDocument = z.infer<typeof rssSchema>
```
